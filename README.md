# Hangman Game

A simple text-based Hangman Game developed using Python.

## Features

- Randomly selects a word from a list of 5 predefined words.
- The player guesses one letter at a time.
- Maximum 6 incorrect guesses are allowed.
- Shows correctly guessed letters.
- Prevents duplicate guesses.
- Displays a winning or game-over message.

## Technologies Used

- Python
- Random Module

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

python hangman.py
